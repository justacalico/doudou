# 20.0.0

- Remove the sliding transition animation when switching between main tabs (Home, Search, Library, Settings) on both mobile and desktop.
- Fix status bar overlap on mobile by adding SafeArea at app level.
- Redesign bottom navigation bar: remove text labels, remove active indicator dot, center active background pill.
- Redesign bottom navigation bar to fully custom non-Material widget using Doudou design tokens (surfaceBase, accentPrimary, surfaceSelected, DoudouMotion).
- Combine mini player into bottom navigation bar widget so they act as one cohesive unit.
- Make mobile mini player a full-width flat bar instead of a floating pill.
- Slim down mini player height from 64 to 56 and reduce album art from 48 to 40.
- Remove slide transition from all content routes (home, album, playlist, search, search results, artist).
- Remove auto-open of now_playing screen on mobile when clicking play - now acts like desktop shell.
- Fix settings screen layout to extend full height in two-pane view.
- Change theme mode selector from dialog to dropdown for consistency.
- Redesign all dropdowns with custom styling including custom icons, colors, and rounded corners.
- Fix theme switching to properly update both GetX and Riverpod theme providers.
- Fix ListTile rendering issues by wrapping in Material widgets to prevent ink splash visibility errors.
- Fix improper GetX Obx usage causing UI unresponsiveness by properly nesting reactive widgets.
- Fix bottom navbar not navigating away when on a settings sub-page (e.g., Servers, Appearance) on mobile.
- Fix settings header alignment on mobile to be left-aligned like other pages.
- Fix back button visibility in light mode by setting AppBar icon theme colors explicitly.
- Fix now playing bottom bar icon visibility in light mode by overriding icon color to white on the dark compact player background.
- Fix home screen quick action card borders not visible in light mode by using theme.dividerColor instead of hardcoded dark-only border color.
- Fix search bar background and border colors in light mode by using theme-aware colors instead of hardcoded dark values.
- Fix switch/toggle "on" state visibility in light mode by adding explicit switchTheme with proper track and thumb colors.
- Remove redundant "Active" badge from Servers settings item and desktop two-pane selected section indicator.
- Hide Favourites quick action card on home screen when user has zero favorites.
- Update home screen favorite count reactively when adding or removing favorites.
- Fix incorrect "Your library is empty" message on home screen when library sections exist.
- Version bump to 20.0.0.
