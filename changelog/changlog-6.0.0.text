# 6.0.0

## Added
- Added an animation when album art changes size.  
- Background for Now Playing.  
- Automatically build .apk files.  
- Indication if a song is being played locally/downloaded or streaming.  
- Added shuffle favorites button for downloaded songs.  

## Changed
- Grey out lyrics if none are available.  
- Lock devices to vertical orientation.  
- Album art is smaller when paused.  
- Refactored the entire audio backend (hopefully less buggy now).  
- Redesigned the home page.  

## Removed
- Music visualizer (not possible with the current audio provider).  
- Now Playing option from the settings screen.  

## Fixed
- Fixed synced lyrics text being hidden in some cases.  
- Fixed offline mode never being set to true.  
- Fixed autoplay.
