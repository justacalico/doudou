# 6.0.0

## Added
- Added an animation when album art changes size.  
- Background for Now Playing.  
- Automatically build .apk files.  
- Indication if a song is being played locally/downloaded or streaming.  
- Added shuffle favorites button for downloaded songs.  
- New options in the drop down menu on now_playing.
- Added kebab menu (three dots) to album details page with download option.
- Enhanced kebab menu with Play Next, Play Later, and Add to Favorites options.
- Added Android Auto*. (Android Auto is still not really there but it works.)

## Changed
- Grey out lyrics if none are available.  
- Lock devices to vertical orientation.  
- Album art is smaller when paused.  
- Refactored the entire audio backend (hopefully less buggy now).  
- Redesigned the home page. 
- Display album name as a title on the album_details page.
- "Play All" -> "Play" on album_details page.
- Bold "Play" & "Shuffle" button's on album_details.
- Moved download album button to kebab menu in navigation bar.
- Completely redesigned now playing screen with improved layout and spacing.

## Removed
- Music visualizer (not possible with the current audio provider).  
- Now Playing option from the settings screen.  
- Removed the abilty to scroll when on the now_playing page.
- Removed year form album_details page.

## Fixed
- Fixed synced lyrics text being hidden in some cases.  
- Fixed offline mode never being set to true.  
- Fixed autoplay.  
- Recently added albums.
- Fixed gapless audio playback.
- Fixed lyrics overlay to automatically reload when track changes during playback.
- Fixed images for top results not working on the search page.
