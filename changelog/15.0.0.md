# 15.0.0

- Unified responsive UI: single set of Dart files for mobile and desktop; sidebar on desktop (≥768px), bottom nav on mobile; removed ui/desktop and ui/mobile folders.
- Navigation service moved to lib/services. Theme consolidated under lib/ui/theme (DesktopTheme + AppleTheme).
- Detail pages, layout, widgets, login, now playing, and settings live under lib/ui with no platform split.
- Login screen removed: app always shows main shell; server setup and Connect/Disconnect moved to Settings; switch server without logging out.
- Page template title: remove yellow underline (explicit TextDecoration.none).
- Settings: reliable scrolling (AlwaysScrollableScrollPhysics, ConstrainedBox in page template); Server URL validation rejects YouTube Music with clear message.
- Removed Dynamic Isle player setting and widget (mini player island).
- Removed General settings section; moved OLED dark mode and Show album art to Appearance under Display.
- Removed Show album art option; OLED dark mode moved to App theme dialog (Choose Theme).
