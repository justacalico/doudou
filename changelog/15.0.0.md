# 15.0.0

- Track list hides ALBUM column on small screens (<500px) so TITLE and ARTIST get more space.
- Fixed SoundCloud autoplay skipping multiple tracks: guard against multiple rapid completion events.
- Playback progress bar: thin track (4px) with circular playhead that extends above and below the bar for easier scrubbing on desktop and mobile.
- Fixed queue skip on track load failure: when a track fails to load (e.g. SoundCloud stream resolution), retry the same track up to 3 times instead of silently advancing to the next; stop with error rather than skipping multiple tracks.
- SoundCloud playlists and favorites are now stored locally (SharedPreferences): create and rename playlists, add/remove tracks, favorite tracks; data persists on device and survives logout.
- Faster SoundCloud playback: run OAuth and embedded client_id resolution in parallel (return first success); fetch scripts in parallel for client_id extraction; pre-warm embedded client_id when token is obtained.
- Fixed SoundCloud album art in desktop now playing: use track.imageUrl when it's a full HTTP URL (SoundCloud, Plex, Subsonic store artwork directly); fall back to getImageUrl for services that resolve IDs (Jellyfin).
- SoundCloud stream resolve: use OAuth instead of Bearer header (per SoundCloud API docs); validate embedded client_id length (≥20 chars) to avoid matching JavaScript variable names.
- Fixed RenderFlex overflow: detail headers (album/artist/playlist) scroll when height is constrained; playback controls row scrolls horizontally on narrow layouts; Shuffle/Download button text ellipsizes; now-playing track info scrolls on small mobile.
- SoundCloud embedded client_id: dedupe script URLs (fetch each unique URL once); skip small scripts (<2KB) without "client_id"; collect URLs from allMatches; broader sndcdn patterns and quoted-URL patterns.
- Search page now uses server-side search: when you type a query (e.g. SoundCloud), results are fetched from the API via searchMedia() with debounce; fixes "No songs found" when library is empty or does not contain the query.
- SoundCloud playback: debug log first 500 chars of page when fetching embedded client_id; try soundcloud.com, /discover, and track page; add client_id= regex; log when embedded fallback runs.
- SoundCloud playback: fallback to api-v2 with embedded client_id (fetched from soundcloud.com page) when official API returns 401.
- SoundCloud playback: use Bearer token and follow 302 redirect to get CDN stream URL (per SoundCloud API #478); skip preview URLs; remove api-v2 fallback (403).
- SoundCloud playback: detailed logs (request URL redacted, status, response prefix); resolve via OAuth then api-v2+client_id; fallback to full api-v2 flow (tracks + progressive transcoding with client_id, sound-on-fire style) when official API returns 401.
- Album/artist detail header: dynamic gradient extracted from album art colors; refined layout with pill-shaped Shuffle and Download buttons, and improved typography and spacing; action buttons wrap on narrow/mobile to fix overflow.
- Cursor rule: update changelog and git commit after every change.
- Home shuffle buttons stack vertically on small windows to avoid overflow.
- Refresh button removed from Home; refresh library is now in Settings (Music Source / Server).
- Refresh button removed from Library page.
- Now playing (mobile, mini player, desktop): when artist name is repeated in a comma-separated list (e.g. "Nia Nicholls, Nia Nicholls, Nia Nicholls"), show a single instance.
- Lyrics overlay: fixed text overflow (yellow underlines) on title, track/artist line, and loading state.
- SoundCloud provider: add as music source using your own app credentials (Client ID and Client Secret from developers.soundcloud.com); search and stream playable tracks via Client Credentials flow.
- SoundCloud sign-in: try OAuth2 token endpoint with redirect_uri; fallback to legacy endpoint; show API error (e.g. invalid_client) on failure; login screen instructs to set Redirect URI to http://localhost/callback in app settings.
- SoundCloud token: try legacy oauth/token first (oauth2/token returns 404), then oauth2/token as fallback to avoid 404 in logs.
- SoundCloud login: added debug logs (kprint from kib_debug_print) for token requests, response status, and errors; timestamps and counters in terminal.
- Fixed SoundCloud sign-in not working: loginWithServerType now has a 'soundcloud' case so the SoundCloud service is used instead of defaulting to Jellyfin.
- SoundCloud logs: use print() as well as kprint so logs always appear in the terminal.
- SoundCloud and release builds: only use kprint and DebugPrintService in debug mode so SoundCloud login works in built/release apps.
- SoundCloud playback: normalize track id (strip soundcloud:tracks: URN prefix), prefer HLS AAC and stream URLs over preview, fallback to /tracks/:id/streams when needed, append client_id to stream URLs; avoid loading empty URL in audio handler.
- SoundCloud library: load playlists (GET /playlists), map playlists to albums so Albums tab shows content, derive artists from track search, getTracks uses search and getPlaylistTracks for parentId, getImageUrl returns HTTP URLs as-is; prefer progressive stream URL first for playback compatibility.
- SoundCloud playback: reject api.soundcloud.com/.../preview URLs (do not work); only use CDN stream URLs; try /streams with URN if numeric id returns nothing; handler skips bad URLs when picking stream.
- SoundCloud playback: reject all api.soundcloud.com URLs for playback (player cannot send Authorization header, so they 401); use only CDN URLs (sndcdn.com, soundcloud.cloud).
- SoundCloud playback: resolve api.soundcloud.com URLs to CDN via HEAD redirect; add playback logs (trackId, URL count, resolve result); handler logs when no URL or URL rejected. KeyUpEvent assertion on Linux is a known Flutter bug.
- SoundCloud playback: log /tracks and /streams response keys; parse transcodings array and resolve relative URLs; resolve relative transcoding URLs to absolute with client_id.
- Home artist cards use person icon for missing art (same as Artists page).
- Home shows distinct sections: Recently added albums (by date), Continue listening (albums from recent playback), Your Artists, Recent Tracks.
- Responsive layout by width: now-playing and detail overlay switch between desktop/mobile layout when window is resized; shared breakpoint (768px).
- Removed Dynamic Isle player (setting and widget).
- OLED dark mode moved from Playback & visuals to Look & language (theme settings).
- Settings page: on small screens, show all sections stacked vertically (no category selector).
- Reduced padding on small screens: sections use 16px instead of 24px, cards use 12px instead of 16px.
- Fixed server settings not loading: now shows server URL and username for all server types (Jellyfin, Subsonic/Navidrome, Plex), not just Jellyfin.
- Notifications (e.g., "Connection successful!") now appear as floating banners at the top of the Settings page, overlaying content without affecting layout.
- Downloads page scaling: action buttons (Play All, Shuffle All) size to content instead of stretching; empty state uses full width with responsive padding and centered content.
- Track list items: long-press on any track opens the options menu (easier than tapping the small three-dots icon on mobile).
- Now-playing context menu: added Download option (shows Download / Downloading… / Downloaded with appropriate icon).
- Downloads preserve favorite status: when a track is downloaded, its favorite status is saved and restored when tracks are loaded.
- Downloads page now shows tracks in a grid of cards (album art, title, artist) instead of a list; tap a card to play from that track.
- When you download a track, album metadata is saved (album + all track info for that album). Downloads are shown by album: grid of albums with at least one downloaded track; tap an album to see all tracks (downloaded ones tappable to play, others greyed out with a download button).
- Fixed overflow issues across all pages: PageTemplate header uses Flexible for title, text widgets have overflow handling (ellipsis), Row widgets replaced with Wrap where appropriate, ListTile text has maxLines/overflow.
- Download service performance: throttled progress updates (max once per 200ms) to prevent excessive UI rebuilds; save operations run asynchronously without blocking downloads.
- Downloads page shows download progress: album cards display progress bars when tracks are downloading; track list items show circular progress indicators and progress bars for active downloads.
- Album detail page: removed album art thumbnails and album name from track list items (redundant since album info is already shown at the top of the page).
- Fixed download button in context menu: properly handles download state, shows error messages when download fails, disables button when already downloaded/downloading, and throws proper exceptions when download URL cannot be retrieved.
- Album download: added Download button to album detail page header (next to Play and Shuffle buttons) that downloads all tracks in the album, with confirmation dialog showing download status and progress feedback.
- Fixed album detail header overflow: action buttons (Play, Shuffle, Download) now use Wrap instead of Row to prevent horizontal overflow on narrow screens.
- Fixed Downloads page header overflow: improved PageTemplate actions layout with proper constraints and text overflow handling for Play All/Shuffle All buttons.
- Fixed Downloads page showing only one album: now groups all downloaded tracks by album (even without stored metadata), so tracks from different albums appear as separate albums in the grid.
- Removed "Show album art" option from Settings page (Playback & visuals section removed as it had no remaining options).
- Removed General Settings from Settings page; default section is now Audio Settings.
- OLED dark mode toggle now applies pure black backgrounds (Material dark theme + DesktopTheme) when enabled.
