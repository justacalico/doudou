# 15.0.0

- Linux: audio backend switched from mpv (media_kit) to audioplayers (GStreamer); no mpv dependency on Linux. Install GStreamer and plugins (e.g. gstreamer, gst-plugins-base, gst-plugins-good, gst-libav) for playback.
- Unified responsive UI: single set of Dart files for mobile and desktop; sidebar on desktop (≥768px), bottom nav on mobile; removed ui/desktop and ui/mobile folders.
- Navigation service moved to lib/services. Theme consolidated under lib/ui/theme (DesktopTheme + AppleTheme).
- Detail pages, layout, widgets, login, now playing, and settings live under lib/ui with no platform split.
- Login screen removed: app always shows main shell; server setup and Connect/Disconnect moved to Settings; switch server without logging out.
- Page template title: remove yellow underline (explicit TextDecoration.none).
- Settings: reliable scrolling (AlwaysScrollableScrollPhysics, ConstrainedBox in page template); Server URL validation rejects YouTube Music with clear message.
- Removed Dynamic Isle player setting and widget (mini player island).
- Removed General settings section; moved OLED dark mode and Show album art to Appearance under Display.
- Removed Show album art option; OLED dark mode moved to App theme dialog (Choose Theme).
- Theme dialog: OLED is a fourth radio option (System Default, Light, Dark, OLED) instead of a separate toggle.
- Connection section: show Jellyfin username from API response (User.Name); fallback to "Logged in" when authenticated but username missing.
- Settings redesigned: iOS-style grouped list (Playback, Appearance, Server, About) with sub-pages; sidebar on desktop, list then detail with back on mobile.
- Removed Android Auto support (automotive metadata and APP_MUSIC intent filter).
- Removed voice commands: Google Assistant App Actions, deep links (doudou://music), MEDIA_PLAY_FROM_SEARCH, and shortcuts; deleted voice_command_handler and voice_command_service.
- Downloads (and other track list) empty state now spans full content area with centered icon and text.
- Home page: removed header (title, greeting, Refresh button); content starts directly with quick access and sections.
- Search page: search bar now spans full width of the header area (Expanded instead of fixed 280px).
- Removed Refresh buttons from Library, Albums, Artists, Playlists, Tracks, album/playlist detail, and Settings (Rescan Library).
- Fully implemented OLED mode: when OLED theme is selected, all surfaces use pure black (#000000)—scaffold, app bar, nav bar, dialogs, bottom sheets, cards, sidebar, mobile player bar—via DesktopTheme and AppleTheme.dark(oled: true); settings page uses theme colors so OLED applies there too.
- Redesigned Choose Accent Color: extracted preset list and _AccentColorDialog widget; 3×2 grid of circular swatches with selection ring and check; Custom Color as a list-style row with chevron; l10n for title and labels; custom picker dialog uses theme, hex preview, and improved sliders.
- Fixed Server settings screen not showing config data when using Navidrome/Subsonic: AppState now keeps displayServerUrl and displayUsername for any server type and sets them on login and session restore; Connection section uses these so Server URL and Username show correctly for Subsonic/Navidrome and Plex.
- Fixed Search page layout crash: search bar no longer uses Expanded inside PageTemplate actions (Expanded was inside Padding, which is invalid); use fixed-width SizedBox(320) so the bar has bounded width.
- Artist detail: Songs and Albums tabs styled as a segmented control (single pill with border, selected segment uses accent fill and white text, unselected segments subtle; same style in desktop layout and artist details page).
- Player bar: added close button (desktop and mobile) that stops playback and clears the queue; AppState.clearQueue delegates to the audio handler; AppState.closePlayerAndClearQueue() and AudioServiceIntegration.stop() added for the close action.
