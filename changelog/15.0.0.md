# 15.0.0

- Now-playing expanded view: album and artist lines under the track title no longer use underline so they are not highlighted as buttons.
- Download option in now-playing more-options menu: start download, cancel downloading, or delete existing download. start download, cancel downloading, or delete existing download.
- Removed leftover unused UI files: lib/ui/widgets/cached_image.dart (replaced by cached_image_widget.dart) and lib/ui/widgets/apple_design/glassmorphism.dart (never imported).
- Fixed close/clear queue button doing nothing: clearing the queue now also clears the current track and emits null to the mediaItem stream so the player bar hides.
- Performance: faster startup (system info logging deferred to after first frame); smoother 60/120 Hz animations on now playing (AnimatedBuilder for skip/snap-back, no setState per tick); heavy work moved off main thread via isolates (dominant color extraction, cache and API JSON parsing for Jellyfin and local music); list items use stable keys and shell uses lazy tab loading; Selector used for playlists/artists/albums pages; track list blur limited to header to reduce GPU cost.
- YouTube Music: prefer 96–160 kbps stream for faster buffer and quicker start; position-based completion fallback on mobile so auto-play and next-track work when stream does not emit completed.
- Lint fixes: guard BuildContext after async in media_details and settings_page (mounted checks); add braces to if/else in now_playing lyrics.
- Server settings screen: Connection section removed; screen now shows Servers list and Cache only.
- Onboarding screen: added theme stage (System default, Light, Dark, OLED) and accent colour stage (preset swatches) after language; flow is Language → Theme → Accent colour → Get Started.
- Onboarding screen when not logged in: welcome message, short app description, and iOS/macOS-style language picker (System default, English, 中文, Русский); "Get Started" completes onboarding and shows the no-server screen.
- Onboarding screen is localized: welcome, description, "Language", "System default", and "Get Started" use app locale (English, Russian, Chinese).
- Artist detail: Albums / Songs tab switch is animated; purple pill slides between tabs (220ms easeInOut).
- Detail header: image-derived gradient fades in over 280ms when it loads (overlay animates out) for a smooth colour transition.
- Detail header: initial background uses page color until image-derived gradient loads, removing the brief flicker when opening album/artist/playlist detail.
- Album and playlist detail: artist name in the header and in each track row is clickable (no underline) and opens the artist page when a matching artist exists in the library.
- Artist detail: Albums / Songs tab bar now spans the full width of the content area; segments share space equally.
- Detail header: Shuffle button is now circular and icon-only (no text), matching the Play button style.
- Detail header (album/artist/playlist) gradient is now derived from the cover image: dominant colors are extracted and darkened for a header gradient that blends into the page background.
- Settings Connection box: handles every provider—Local (Music Source, directories, scan), YouTube Music (Provider, no URL/Test Connection), Jellyfin/Plex/Subsonic (Server URL, Username, Test Connection); badge and labels vary by type.
- Linux: YouTube Music option disabled in Server type dropdown and in saved servers list; on startup, if current server was YouTube Music, app switches to another saved server or disconnects.
- Linux YouTube Music: fix no audio ("Audio output auto not found") by writing `~/.config/mpv/mpv.conf` with explicit audio driver `ao=pulse,pipewire,alsa` when media_kit is used for YT on Linux. PulseAudio, PipeWire, or ALSA should be available for mpv; added `media_kit_libs_linux` for compatibility.
- Linux: set C locale at process start (setlocale(LC_ALL, "C") in native runner main.cc) so YouTube Music playback does not crash with "Non-C locale detected"; Dart-side fallback uses LC_ALL and debug logging.
- Linux: packaged desktop file launches with env LC_ALL=C as a safeguard.
- Desktop: detail header action buttons (Play, Shuffle) no longer overflow on narrow panels; wrapped in horizontal SingleChildScrollView.
- Linux: YouTube Music playback enabled via media_kit (mpv) for YT streams only; setlocale(LC_NUMERIC, "C") is applied before loading mpv to avoid "Non-C locale" crash. Other Linux playback still uses audioplayers (GStreamer).
- Search page: shows albums, artists, and songs for all providers; YouTube Music also shows community playlists with tap-to-open.
- When changing servers (connect or switch), the queue is cleared and playback is stopped.
- YouTube Music added as a media provider: select "YouTube Music" in Server type to stream without login; search from the Search page to find and play tracks. YT Music code is isolated from the main audio stack so it cannot affect Linux system audio. On Linux, playback uses GStreamer only (no mpv); YouTube streams may not play due to GStreamer limitations.
- Dates shown in the app now use year/month/day format (e.g. 2025/02/21) everywhere: album "Added" date, Settings build date, and log file names/timestamps.
- Fixed "Looking up a deactivated widget's ancestor" when tapping OK (or other buttons) on Apple-style dialogs: all showAppleDialog call sites now use actionsBuilder so buttons use the dialog's context for Navigator.pop instead of the caller's, avoiding crashes when the calling screen was already closed (e.g. Share Track on now playing).
- Linux: audio backend switched from mpv (media_kit) to audioplayers (GStreamer); no mpv dependency on Linux. Install GStreamer and plugins (e.g. gstreamer, gst-plugins-base, gst-plugins-good, gst-libav) for playback.
- Unified responsive UI: single set of Dart files for mobile and desktop; sidebar on desktop (≥768px), bottom nav on mobile; removed ui/desktop and ui/mobile folders.
- Navigation service moved to lib/services. Theme consolidated under lib/ui/theme (DesktopTheme + AppleTheme).
- Detail pages, layout, widgets, login, now playing, and settings live under lib/ui with no platform split.
- Login screen removed: app always shows main shell; server setup and Connect/Disconnect moved to Settings; switch server without logging out.
- Page template title: remove yellow underline (explicit TextDecoration.none).
- Settings: reliable scrolling (AlwaysScrollableScrollPhysics, ConstrainedBox in page template); Server URL validation rejects YouTube Music with clear message.
- Removed Dynamic Isle player setting and widget (mini player island).
- Removed General settings section; moved OLED dark mode and Show album art to Appearance under Display.
- Removed Show album art option; OLED dark mode moved to App theme dialog (Choose Theme).
- Theme dialog: OLED is a fourth radio option (System Default, Light, Dark, OLED) instead of a separate toggle.
- Connection section: show Jellyfin username from API response (User.Name); fallback to "Logged in" when authenticated but username missing.
- Settings redesigned: iOS-style grouped list (Playback, Appearance, Server, About) with sub-pages; sidebar on desktop, list then detail with back on mobile.
- Removed Android Auto support (automotive metadata and APP_MUSIC intent filter).
- Removed voice commands: Google Assistant App Actions, deep links (doudou://music), MEDIA_PLAY_FROM_SEARCH, and shortcuts; deleted voice_command_handler and voice_command_service.
- Downloads (and other track list) empty state now spans full content area with centered icon and text.
- Home page: removed header (title, greeting, Refresh button); content starts directly with quick access and sections.
- Search page: search bar now spans full width of the header area (Expanded instead of fixed 280px).
- Removed Refresh buttons from Library, Albums, Artists, Playlists, Tracks, album/playlist detail, and Settings (Rescan Library).
- Fully implemented OLED mode: when OLED theme is selected, all surfaces use pure black (#000000)—scaffold, app bar, nav bar, dialogs, bottom sheets, cards, sidebar, mobile player bar—via DesktopTheme and AppleTheme.dark(oled: true); settings page uses theme colors so OLED applies there too.
- Redesigned Choose Accent Color: extracted preset list and _AccentColorDialog widget; 3×2 grid of circular swatches with selection ring and check; Custom Color as a list-style row with chevron; l10n for title and labels; custom picker dialog uses theme, hex preview, and improved sliders.
- Fixed Server settings screen not showing config data when using Navidrome/Subsonic: AppState now keeps displayServerUrl and displayUsername for any server type and sets them on login and session restore; Connection section uses these so Server URL and Username show correctly for Subsonic/Navidrome and Plex.
- Fixed Search page layout crash: search bar no longer uses Expanded inside PageTemplate actions (Expanded was inside Padding, which is invalid); use fixed-width SizedBox(320) so the bar has bounded width.
- Artist detail: Songs and Albums tabs styled as a segmented control (single pill with border, selected segment uses accent fill and white text, unselected segments subtle; same style in desktop layout and artist details page).
- Player bar: added close button (desktop and mobile) that stops playback and clears the queue; AppState.clearQueue delegates to the audio handler; AppState.closePlayerAndClearQueue() and AudioServiceIntegration.stop() added for the close action.
- Multi-server management: add, edit, remove, and switch between saved servers without reloading. Settings > Server shows a list of saved servers with Switch / Edit / Remove; Add server opens the connection form; connecting saves the server and sets it as current; legacy single-server prefs are migrated into the list on first load.
- Lyrics screen: removed yellow underline on text (title, song/artist, loading message, and lyric lines) by setting decoration: TextDecoration.none on all relevant Text styles in lyrics overlay and desktop lyrics view.
- Dark mode vs OLED: dark mode now uses a dark gray (charcoal) for all backgrounds (e.g. #1C1C1E) like the settings bar; OLED mode remains pure black (#000000) for all surfaces.
- Gemini redesign: dark mode palette updated to match (#0a0a0c page, #0e0e11 sidebar, #121216 main, #16161c detail); sidebar restyled with purple logo box and shadow, rounded nav tiles (white/10 active, white/5 hover), Library label, and Settings button with purple tint and border at bottom.
- Settings sidebar (desktop): Gemini-style list with "Settings" title, uppercase section headers (PLAYBACK, APPEARANCE, SERVER, ABOUT), rounded cards per item with colored icon box, label, section subtitle, status (e.g. Connected in green), and chevron; detail panel uses #16161c background.
- Settings popouts (Select Language, Choose Theme, accent/custom color) redesigned Apple-style: frosted glass (backdrop blur), large rounded corners, soft shadow, scale/fade animation; selection options use checkmark circle when selected instead of radio buttons.
- All app dialogs and popouts use Apple-style design: added showAppleConfirmDialog and showAppleChoiceDialog; replaced AlertDialog/CupertinoAlertDialog across settings, desktop layout, media details, track list template, local music settings, now playing, artist detail, download button, and detail track view with frosted glass dialogs.
- Mobile: removed black box behind navbar and now-playing bar by using extendBody so content draws behind the bars and both bars use frosted glass (semi-transparent + blur) instead of solid fill; player bar no longer uses solid OLED background.
- Mobile: added bottom padding to body when extendBody is true so now playing and other content are not covered by the nav bar (72px + safe area).
- Add server / Edit server dialog: Cancel button now uses dialog context for Navigator.pop; actionsBuilder is invoked from inside the dialog widget so the passed context stays mounted when the button is tapped, fixing "Looking up a deactivated widget's ancestor is unsafe."
- Add server / Edit server: Server type selection changed from horizontal chips to a dropdown (Jellyfin, Plex, Subsonic, Local).
- Local music UI removed: standalone Local Music screen deleted; local music is configured only in Settings.
- Servers now persist: Add/Edit server dialog awaits setCurrentServerAndSave so SharedPreferences write completes before closing; onConnectSuccess is async and awaited in all connect paths (normal, local, Quick Connect). Add server > Local shows a short message and Connect (no "Configure local music" screen). Settings sidebar shows "Local Music" when current server is local; Server section includes Music Directories, Add Directory, Scan for Music, Fetch Online Artwork, and cache options. Local connect allowed with empty library (add folders in Settings after connecting).
- Fixed add/switch server kicking you off Settings: when the page list is rebuilt (e.g. switching between local and remote server), the shell now keeps the selection on Settings instead of leaving the tab or highlighting the wrong item.
- Settings reorganized: Server (connection) first, then Playback, Appearance, About.
- Single Now Playing screen for mobile and desktop: one responsive screen (lib/ui/playing/now_playing.dart) scales by width (breakpoint 900px). Compact layout keeps mobile carousel, progress, controls, queue/favorite/lyrics/more bar; expanded layout shows album + controls on the left and Up Next / Lyrics tabs on the right, with gradient background and “The Mind Electric” easter egg. Desktop no longer uses a separate overlay; it pushes the same NowPlayingScreen.
- Dead code and refactor cleanup: Home page "more" button on recent tracks now opens track menu (Add to Playlist, Go to Album, Go to Artist). Add-to-playlist consolidated: DesktopLayout.showAddToPlaylistDialog includes "Create New Playlist" and is used from now-playing and home; duplicate dialog and helpers removed from now_playing. Artist detail screens (ArtistDetailScreen vs ArtistDetailsPage) documented with comments.
