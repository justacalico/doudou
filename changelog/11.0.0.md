## Changed

- **Unified Audio Handler**: Refactored audio system from 4 platform-specific handlers (~4,200 lines) into a single cross-platform `UnifiedAudioHandler` (~1,550 lines). Works seamlessly on mobile (Android/iOS), desktop (Linux/macOS/Windows), and web with platform-specific features (foreground service, wake lock, media_kit backend, CORS handling) handled internally via conditional logic.

- **Desktop Now Playing Panel**: The Up Next and Lyrics tabs now share the same album art background as the main player view instead of having their own separate background, creating a more unified look similar to YouTube Music.
