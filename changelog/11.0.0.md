# 11.0.0

## Added

- **Easter Egg**: The desktop fullscreen Now Playing view flips horizontally when "The Mind Electric" is playing, as a tribute to the song's famous reversed/backwards section.

## Changed

- **Unified Audio Handler**: Refactored audio system from 4 platform-specific handlers (~4,200 lines) into a single cross-platform `UnifiedAudioHandler` (~1,550 lines). Works seamlessly on mobile (Android/iOS), desktop (Linux/macOS/Windows), and web with platform-specific features (foreground service, wake lock, media_kit backend, CORS handling) handled internally via conditional logic.

- **Complete Desktop UI Redesign**: Completely rewrote the desktop interface from scratch with a modern, Spotify-inspired design:
  - **Streamlined Layout**: Reduced code from ~4,055 lines to ~1,940 lines (52% reduction) while improving functionality
  - **Modern Sidebar**: Clean navigation with hover effects, accent color highlighting, and organized library sections
  - **Optimized Player Bar**: Sleek bottom player with hoverable progress bar, track info, playback controls, volume slider, and queue access
  - **Full-Screen Now Playing**: Beautiful overlay with blurred album art background, large artwork display, progress controls, and tabbed queue/lyrics panel
  - **Performance Optimizations**: Efficient widget rebuilds using StreamBuilder patterns, proper state management, and minimal redraws
  - **Keyboard Shortcuts**: Space for play/pause, Ctrl+Arrow for skip
  - **Add to Playlist Dialog**: Elegant dialog for adding tracks to playlists

- **Desktop Now Playing Panel**: The Up Next and Lyrics tabs now share the same album art background as the main player view instead of having their own separate background, creating a more unified look similar to YouTube Music.

- **Inline Detail Pages**: Album, artist, and playlist detail views now render within the main desktop layout instead of navigating to a separate page. The sidebar remains visible for consistent navigation, with a back button to return to the previous view. Updated home page and search page to use inline navigation.

## Fixed

- **Desktop Artists Page Layout**: Fixed squished artist cards by implementing a responsive grid that adapts to screen width (minimum 150px per card, 2-8 columns) with improved aspect ratio for better display of circular artist images.

- **Desktop Search Page Crashes**: Fixed "RenderAspectRatio has unbounded constraints" crash in search results by properly sizing artwork containers. Added mounted checks to hover state callbacks to prevent setState calls after widget disposal.

- **Desktop Now Playing Updates**: Fixed Now Playing overlay not updating when the current song changes. The overlay now uses StreamBuilder to listen to mediaItem changes in real-time.

- **Desktop Album Cards Overflow**: Fixed "BOTTOM OVERFLOWED BY X PIXELS" error on album cards by simplifying the info section layout and removing unnecessary flex constraints.
