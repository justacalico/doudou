# 21.0.0

- Bumps version to 21.0.0
- Updates dependencies
- Adds Android Auto support
- Adds Wear OS companion app with playback controls, shuffle all, favorites, and settings (#207)
- Fixes duplicate lyrics bottom sheets spawning when the lyrics button is tapped rapidly (#208)
- Opens lyrics bottom sheet instantly with content loading asynchronously
- Fixes adding music to playlists on Subsonic servers (#211)
- Fixes loading album details sometimes failing with HiveError when the downloads box hasn't been opened yet (#213)
- Adds right-click and long-press support to open song options across all song lists, queue, artist table, and home screen sections (#212)
- Fixes crash when getWatchPlaylist response is missing playlistPanelRenderer (#214)
- Fixes favorite status not showing or toggling correctly in song options for Subsonic and other non-YouTube servers (#215)
- Adds Android TV support with D-pad navigation, focus highlighting, and 10-foot UI adaptations (#208)
- Adds `tv` product flavor with leanback launcher, separate `applicationIdSuffix .tv`, and `versionCode` offset for Play Store multi-APK delivery
- Disables YouTube Music on TV builds via `PLAYSTORE` compile flag (same as Play Store phone builds)
- Adds `TvService` for runtime TV detection using `device_info_plus`
- Adds `DoudouLayoutClass.tv` with wider content area, larger padding, and side navigation for D-pad
- Adds `TvFocusHighlight` widget for visible focus rings on interactive elements
- Disables sliding panel drag and slidable swipe actions on TV (no touchscreen)
- Enables queue drawer on TV layouts
- Adds Discord Rich Presence support for desktop platforms (Linux, macOS, Windows) — users can enter their Discord Application ID in Settings > Misc to show the current song as their Discord activity status
- Fixes second window opening as black screen on desktop — launching a second instance now focuses the existing window instead (Linux, Windows, macOS)
- Changes compact desktop volume button to open a vertical volume slider popup on left click; right-click still mutes or unmutes audio
