# 22.0.0

- Bumps version to 22.0.0
- Adds Android TV support with D-pad navigation, focus highlighting, and 10-foot UI adaptations (#208)
- Adds `tv` product flavor with leanback launcher, separate `applicationIdSuffix .tv`, and `versionCode` offset for Play Store multi-APK delivery
- Disables YouTube Music on TV builds via `PLAYSTORE` compile flag (same as Play Store phone builds)
- Adds `TvService` for runtime TV detection using `device_info_plus`
- Adds `DoudouLayoutClass.tv` with wider content area, larger padding, and side navigation for D-pad
- Adds `TvFocusHighlight` widget for visible focus rings on interactive elements
- Disables sliding panel drag and slidable swipe actions on TV (no touchscreen)
- Enables queue drawer on TV layouts
- Updates CI pipeline with `build-android-tv-debug` job
