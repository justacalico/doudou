### Additional Notes for Play Console:

1. **Independent app**: This app operates independently and only connects to user-provided Jellyfin servers

2. **Local storage only**: The only data stored is:
   - Server connection settings (stored locally on device)
   - User preferences (stored locally on device)
   - Temporary audio cache (stored locally on device)

3. **No third-party libraries** that collect data:
   - No analytics SDKs
   - No advertising SDKs  
   - No crash reporting SDKs that send data externally

4. **Open source**: Full transparency through open source code availability
