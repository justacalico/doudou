# Fastlane Images Directory

This folder should contain the following images for F-Droid and Play Store listings:

## Required Images

### icon.png (512x512)
- App icon in PNG format
- Must be exactly 512x512 pixels
- No transparency recommended

### featureGraphic.png (1024x500)
- Feature graphic shown at top of store listing
- Must be exactly 1024x500 pixels
- Used for promotional purposes

### phoneScreenshots/ (1-8 images)
- Screenshots of the app running on a phone
- Recommended size: 1080x1920 or similar portrait
- Name format: 1.png, 2.png, etc.
- Minimum 1 screenshot, maximum 8

## Optional Images

### tabletScreenshots/ (1-8 images)
- Screenshots of the app running on a tablet
- Recommended size: 1920x1080 or similar landscape

### tvBanner.png (1280x720)
- Banner for Android TV listings

## Notes

- All images should be in PNG format
- Do not use placeholders - only include actual screenshots
- Screenshots should showcase key features of the app
